MCP Tools — AI Agent Consumption

🔍 Read — no state change
get_incidentREAD
Retrieve a single incident by its internal UUID.
idInternal UUID of the incident
list_incidentsREAD
List incidents with optional filters. All parameters are combinable.
severityoptionalLOW · MEDIUM · HIGH · CRITICAL
statusoptionalOPEN · IN_PROGRESS · RESOLVED · CLOSED
reportedByoptionalFilter by reporter name or ID
get_incident_historyREAD
Retrieve the full audit trail for an incident, ordered by time ascending.
idInternal UUID of the incident
suggest_resolutionREAD · AI
Suggest a resolution by semantically searching past resolved incidents and generating an AI-powered action plan. Requires resolved incidents to be indexed first.
idInternal UUID of the incident to analyse
✏️ Mutation — modifies state
create_incidentMUTATION
Create a new incident. Idempotent — returns the existing incident if the same externalReferenceId was already submitted.
titleShort descriptive title
severityLOW · MEDIUM · HIGH · CRITICAL
reportedByName or ID of the person reporting
externalReferenceIdoptionalIdempotency key
update_incident_statusMUTATION
Advance an incident's status. Valid transitions only: OPEN→IN_PROGRESS→RESOLVED→CLOSED. Invalid skips return HTTP 422.
idInternal UUID of the incident
statusIN_PROGRESS · RESOLVED · CLOSED
changedByName or ID of the person making the change
notesoptionalNotes about the change
